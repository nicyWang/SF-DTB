## 一、产品定义（一句话）

**给中小企业主和重度电脑用户的"全天候桌面AI搭档"——动嘴即办事：它能听、能想、能操作你的电脑、能记住你。**

价值主张三角：
- **功能价值**：一句话完成 20+ 类电脑任务（打开应用/整理桌面/放歌/设闹钟/搜索/发微信）
- **情感价值**：有形象、有表情、有情绪的陪伴感（不是冷冰冰的对话框）
- **效率价值**：不用切窗口、不用打字、不用学——说话就是最快的人机接口

## 二、目标用户画像（Persona）

### 主Persona：汪总（也是首发种子用户）
- **身份**：乐畔里自助KTV连锁品牌主理人 + 企业AI自动化服务创业者
- **设备**：MacBook Pro，全天开机，多应用并行（微信/酷狗/备忘录/浏览器/表格）
- **场景**：办公时手忙脚乱——想边看资料边放音乐边回消息；希望"说一句就有人办"
- **痛点强度**：★★★★★（高频操作琐碎、切窗口打断心流）
- **付费意愿**：高（自己有AI落地业务，愿意为效率工具持续付费）
- **核心诉求**："我要的是：我说整理桌面，他就能整理桌面；我说放首歌，他就能放首歌"

### 副Persona：知识工作者/主播
- 直播时弹幕互动（P2，暂缓）
- 长文档/会议纪要处理（P2）

## 三、需求清单（MoSCoW 分级）

### Must-have（P0 · MVP必须 · 缺一个就不算产品）

| # | 需求 | 验收标准 | 现状 |
|---|---|---|---|
| M1 | **稳定语音对话** | 连续5轮对话零失败；说完到开口≤3s；嘈杂环境可用 | ✅ 已达（回归13/13） |
| M2 | **一句话任务执行** | "打开微信/放首歌/设闹钟/整理桌面/关XX/搜XX" 六类全部真实完成 | ✅ 已达（工具链全通） |
| M3 | **完成有实证** | 声称完成必须有证据（进程/声音/界面变化），不撒谎 | ✅ 已达（验证器框架） |
| M4 | **情感化表达** | 表情跟回复情绪；语音语调带情感 | ✅ 已达（本轮修复） |
| M5 | **可靠降级** | 任何环节失败→明确提示+可用兜底，绝不无限循环或沉默 | ⚠️ 基本达标（冷却已加） |
| M6 | **可拖拽/常驻桌面** | 小球可拖到任意位置、置顶不挡事 | ✅ 已达 |

### Should-have（P1 · 第二迭代 · 决定"好用不好用"）

| # | 需求 | 验收标准 | 现状 |
|---|---|---|---|
| S1 | 屏幕理解问答 | "我屏幕上是什么/这个按钮干嘛的"准确回答 | ✅ 能力在，准确率待提 |
| S2 | 精准UI操控 | 常见应用按钮点击成功率≥80% | ⚠️ 60-70%（AX树+验证器已建） |
| S3 | 记忆系统 | 记住偏好（常用应用/口味/称呼），越用越懂你 | 🔶 基础在，未显性化 |
| S4 | 多轮上下文 | "再放大声点""刚才那个开一下"指代理解 | 🔶 部分 |
| S5 | 微信消息发送+读取 | "给XX发消息说XX"真实送达 | ✅ wechat-send已有 |
| S6 | 文档/图片处理 | PDF转Word/图片压缩/剪贴板翻译 | ✅ 已有4个Skill |

### Could-have（P2 · 有则更好 · 不影响核心）

| # | 需求 | 说明 |
|---|---|---|
| C1 | 抖音弹幕互动 | 直播场景（汪总业务相关，但非办公核心） |
| C2 | 多形象商城 | 云朵兔之外的角色（立绘成本高） |
| C3 | 性格演化 | 随交互塑造个性（已有引擎，待内容） |

### Won't-have（本期明确不做）

| # | 不做 | 原因 |
|---|---|---|
| W1 | 手机端 | 桌面场景优先，端不分散兵力 |
| W2 | 自由对话式GUI操控（"帮我做PPT"） | 当前模型能力撑不住，成功率<40%会毁信任 |
| W3 | 通用Agent平台/插件市场 | 先服务好一个用户，再谈生态 |
| W4 | Windows版 | macOS先行（AX树整套是darwin-only） |

## 四、多维分析（产品多维分析工具 · 现状审查）

### UX 维度
| 问题 | 严重度 | 建议 |
|---|---|---|
| 语音失败时用户不知道该重说还是等待 | 高 | 状态可视化为三态：听/想/说（已有基础，需统一） |
| 设置项27个键，用户无从下手 | 中 | 收敛为"服务配置/形象/行为"三区，高级项折叠 |
| 完成播报冗长（"好啦好啦～微信打开咯🥺怎么啦是要找..."） | 中 | 任务类回执≤15字+证据；闲聊才展开 |

### 架构维度（承接上午的复盘）
| 问题 | 严重度 | 建议 |
|---|---|---|
| 语音30+路径组合 | 高 | 主路豆包WS+单兜底（已定方案） |
| 6渲染器并存 | 高 | 收敛到emotion-ball |
| 37工具双命名 | 中 | 合并为25个kebab-case |
| pet.js 1511行 | 高 | 拆5模块 |

### 差异化壁垒（竞争分析）
| 竞品 | 它们的做法 | 我们的差异 |
|---|---|---|
| OpenAI Operator/CUA | 云端Agent操作浏览器，38%成功率 | **本地AX树直控**：系统级元素索引，快且准；数据不出本机 |
| 传统桌宠（桌面精灵类） | 卖萌无能力 | 真实任务执行+物理级验证 |
| Siri/小爱 | 系统级但能力封闭、不可扩展 | 开放工具框架，一句话直达任意应用 |
| ChatGPT桌面版 | 对话强但"不能动你的电脑" | 情感陪伴+操作能力一体 |

**核心壁垒排序**：① 本地AX操控+验证器（别人做不了或做得慢）② 情感化体验（语音+表情+性格）③ 记忆个性化（时间壁垒）

## 五、北极星指标与验收

**北极星**：每周"真实完成的任务数"（有证据的任务执行次数）
- 种子期（汪总自用）：≥50次/周，成功率≥90%
- 目标：用户第7天仍保持日均10+次语音指令

**反指标**（警惕）：失败重试率>30%（说明不可靠）、"没反应"类反馈（说明沉默失败）
