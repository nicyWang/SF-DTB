# 角色生成 Skill — 提示词工程系统

> 桌宠角色工坊的核心资产：把用户输入（照片特征/表单描述）转化为高质量生图提示词。
> 设计原则：**模板化槽位填充 + 风格锚定词 + 质量保障词**，确保不同用户输入都能产出风格统一、可用作桌宠的立绘。

## 一、风格模板（三选一）

### 1. 写实摄影风（默认）
```
写实人像摄影风立绘：{age}{gender}，{face}，{hair}，{clothing}，{temperament}，
时尚杂志大片质感，高级打光突出面部立体感，人物居中完整呈现全身，
站姿自然，构图人物占画面80%以上，
浅灰色纯色摄影棚背景（背景均匀无渐变无阴影），
高质量细节，8K画质，专业人像摄影
```

### 2. 精致动漫风
```
高质量动漫立绘：{age}{gender}，{face}，{hair}，{clothing}，{temperament}，
精致日系动画风格，细腻上色，干净利落的线条，
人物居中全身立绘构图，站姿自然有亲和力，
浅灰色纯色背景（均匀无渐变），
高清细节，专业插画水准
```

### 3. 游戏CG风
```
游戏角色立绘CG：{age}{gender}，{face}，{hair}，{clothing}，{temperament}，
精致的游戏立绘质感，光影层次丰富，细节华丽，
人物居中全身构图，站姿自然，
浅灰色纯色背景（均匀无渐变），
高质量渲染，次世代游戏CG水准
```

## 二、槽位词库

### gender（性别）
男 / 女

### age（年龄段）
- 18-22岁青春感 / 23-27岁 / 28-35岁成熟感 / 36-45岁知性优雅

### face（面部气质，可组合2-3个）
男性：帅气硬朗 / 剑眉星目 / 温润儒雅 / 深邃眼眸 / 高挺鼻梁 / 轮廓分明 / 阳光开朗 / 冷峻贵气
女性：精致面容 / 明眸善睐 / 温柔甜美 / 气质出众 / 五官立体 / 笑容治愈 / 御姐气场 / 清纯可人

### hair（发型发色）
男性：黑色短发干净利落 / 微卷短发时尚感 / 侧分长发艺术家气质 / 寸头硬朗
女性：长直发黑亮 / 大波浪卷发妩媚 / 齐肩短发干练 / 高马尾活泼 / 双马尾可爱

### clothing（服装，按气质匹配）
商务精英：修身西装+白衬衫 / 商务休闲西装
阳光休闲：卫衣+牛仔裤 / T恤+休闲裤
优雅礼服：晚礼服 / 修身连衣裙
可爱系：JK制服 / 洛丽塔裙装
运动系：运动套装 / 瑜伽服

### temperament（整体气质，决定"性感/魅力"的度）
- 成熟魅力型：气质优雅自信，身姿挺拔，举手投足间散发魅力
- 阳光活力型：笑容灿烂，元气满满，青春活力四射
- 温柔治愈型：气质温柔，眼神柔和，让人如沐春风
- 高冷御姐型：气场强大，眼神自信，霸气侧漏
- 甜美可爱型：俏皮灵动，甜美动人，少女感十足

## 三、照片转绘流程（vision特征提取）

照片上传后，用LLM vision按以下prompt提取特征（要求只回JSON）：

```
分析这张人物照片，提取以下特征并以JSON返回（只回JSON不要其他文字）：
{
  "gender": "男或女",
  "age_band": "18-22|23-27|28-35|36-45 之一",
  "face": "2-3个面部气质关键词，参考：帅气硬朗/精致面容/温柔甜美等",
  "hair": "发型+发色描述",
  "clothing": "照片中的服装描述",
  "temperament": "整体气质关键词"
}
```

提取结果填入风格模板生成转绘提示词，转绘时在模板追加：
```
参考照片人物的面部特征和气质，保持人物辨识度
```

## 四、质量保障词（所有模板固定追加）

- `人物居中完整呈现全身`（保证立绘完整性）
- `浅灰色纯色摄影棚背景（背景均匀无渐变无阴影）`（保证chroma key可处理）
- `构图人物占画面80%以上`（减少背景占比，trim后效果好）
- `高质量细节，专业水准`（画质保障）

## 五、程序化表情滤镜映射（单图角色的情绪近似）

| 情绪 | PIXI ColorMatrixFilter参数 | 变换 |
|------|---------------------------|------|
| normal | 原图 | 原始 |
| happy | brightness(+0.08) saturation(+0.10) | scale 1.02 |
| excited | brightness(+0.12) saturation(+0.18) | scale 1.05 + 轻微摇摆 |
| sad | brightness(-0.08) saturation(-0.25) | scale 0.99 + 轻微下垂位移 |
| sleepy | brightness(-0.12) saturation(-0.15) | scale 1.0 + 缓慢呼吸加深 |
| bored | brightness(-0.04) saturation(-0.12) | scale 0.99 |

## 六、默认参数

- 生成尺寸：1024x1536（竖版立绘）
- 生成数量：1张（normal主图）
- 生成后自动：chroma key → trim → 注册角色 → 可选立即切换
